# Первый запуск Frontsmith: инструкция для тестировщика

Эта инструкция для человека, который видит Frontsmith впервые. Она проводит от клонирования репозитория до первого клиента и проверки AI. Состояние релиза: **READY FOR EXTERNAL TESTING** — установка с нуля на другом компьютере ещё не проверялась, ваш запуск и есть эта проверка.

Frontsmith — универсальный цифровой офис небольшой сервисной компании: клиенты, обращения, задачи, услуги, расписание и AI-помощник через Codex. Данные остаются на вашем компьютере.

## 1. Системные требования

- Windows 10 или 11, 64-битная (x64). Linux и macOS в этом релизе не поддерживаются.
- Node.js 20 или новее с npm: https://nodejs.org.
- Git for Windows: https://git-scm.com. Git LFS входит в него.
- Codex CLI для проверки AI: приложение Codex или `npm install -g @openai/codex`. Frontsmith ищет `codex.exe` в `%LOCALAPPDATA%\OpenAI\Codex\bin`, затем `codex` в `PATH`; другой путь можно задать переменной `CODEX_BIN`.
- Подписка ChatGPT с доступом к Codex. OpenAI API key не нужен.
- Свободное место: около 1,2 ГБ под репозиторий и не меньше 4 ГБ на диске, где будут данные Frontsmith (после установки занято около 1,5 ГБ).
- Интернет для клонирования, `npm install` и AI. Сама установка (`npm run bootstrap`) работает без сети.

Docker, Go и Python ставить не нужно.

## 2. Клонирование

Откройте PowerShell или терминал Git Bash в папке, где будет лежать проект, и выполните:

```bash
git lfs install
git clone https://github.com/vionaaru/codex-frontsmith.git
cd codex-frontsmith
```

`git lfs install` нужен один раз на компьютере: без него вместо больших файлов скачаются маленькие текстовые указатели.

## 3. Проверка Git LFS

```bash
git lfs pull
git lfs ls-files
```

`git lfs ls-files` должен показать 89 файлов, среди них `vendor/ner-model/rubert-base-pii-ner/model.safetensors`. У настоящих файлов перед именем стоит `*`; знак `-` означает, что файл не получен — повторите `git lfs pull`.

Затем установите зависимости Node.js:

```bash
npm install
```

## 4. Выбор каталога данных

При первом `npm run bootstrap` Frontsmith спросит, где хранить данные:

```text
Выберите каталог для хранения данных:

[ C:\Users\<вы>\AppData\Local\Frontsmith ]
```

Нажмите Enter, чтобы согласиться, или введите другой путь, например `E:\Frontsmith`. Каталог должен быть вне папки `codex-frontsmith`: там будут контакты CRM, состояние защиты персональных данных, установленный runtime, вход Codex и резервные копии. Frontsmith проверит диск, право на запись и свободное место и при проблеме попросит другой путь.

Выбор запоминается. Чтобы задать каталог без вопроса: `npm run bootstrap -- --data-root "E:\Frontsmith"`.

## 5. Bootstrap

```bash
npm run bootstrap
```

Первый запуск занимает несколько минут: Frontsmith проверяет файлы поставки по SHA-256, ставит Python и пакеты, готовит CRM, создаёт профиль компании и проверяет службу защиты персональных данных. Загрузка модели на слабом компьютере может идти до 10 минут.

В конце должно быть:

```text
Frontsmith bootstrap complete

Business DB:    ready
CRM:            ready
Privacy:        ready
CustomerModule: ready
Codex:          sign-in required
```

`Codex: sign-in required` до следующего шага — нормально. Повторный `npm run bootstrap` ничего не переустанавливает и не меняет данные; его можно запускать для проверки.

Если вместо этого появилась ошибка `LFS_OBJECTS_MISSING`, вернитесь к шагу 3.

## 6. Авторизация Codex

```bash
npm run codex-host:login
```

Откроется вход Sign in with ChatGPT. Войдите в аккаунт с подпиской. Вход хранится в каталоге данных Frontsmith отдельно от вашего обычного Codex.

## 7. Запуск Frontsmith

```bash
npm run frontsmith
```

Дождитесь строк:

```text
Frontsmith ready

Office:         http://127.0.0.1:4180
...
Office ready: yes · AI ready: yes
```

Окно должно оставаться открытым, пока вы работаете. Остановка — Ctrl+C в этом окне.

## 8. Панель офиса

Откройте в браузере `http://127.0.0.1:4180`. Панель доступна только с этого компьютера. В новой установке нет клиентов, услуг и обращений — это ожидаемо. Разделов про автомобили и заказ-наряды тоже нет: они только в профиле автосервиса.

## 9. Первый клиент

В панели откройте «Клиенты» и нажмите «Новый клиент». Заполните имя, телефон и, при желании, email. Используйте выдуманные данные, например «Тестовый Клиент», `+7 900 000-00-01`. Нажмите «Создать клиента».

Клиент появится в списке. Его контакты сохраняются во встроенной CRM в каталоге данных, а в базе офиса остаётся только идентификатор.

## 10. Проверка CRM

1. Остановите Frontsmith (Ctrl+C) и снова выполните `npm run frontsmith`.
2. Откройте «Клиенты»: созданный клиент на месте, телефон отображается.
3. Найдите клиента через поиск по части имени или телефона.

Если вместо телефона показано «контакт недоступен», CRM не отвечает: сохраните вывод `npm run frontsmith` и сделайте отчёт по шагу 12.

## 11. Проверка AI

Остановите Frontsmith (Ctrl+C) и выполните:

```bash
npm run smoke:codex-host
```

Проверка отправляет в Codex сообщение с выдуманными персональными данными и убеждается, что до модели они доходят только в замаскированном виде, а ответ восстанавливается для вас. Она тратит немного лимита подписки. Ожидаемый итог — все строки `PASS`. `SKIPPED` означает, что нет входа ChatGPT (шаг 6) или Codex CLI не найден.

## 12. Диагностический отчёт при ошибке

```bash
npm run diagnostics
```

Команда печатает версии Windows, Node.js, Git и Git LFS, состояние файлов поставки, каталога данных, CRM, службы защиты данных и Codex, а также количества записей. Контактов клиентов, токенов, входа ChatGPT и содержимого псевдонимизации в отчёте нет; путь вашей папки пользователя заменён на `%USERPROFILE%`.

В сообщение об ошибке приложите:

- вывод `npm run diagnostics`;
- команду, которая не сработала, и её полный вывод;
- на каком шаге этой инструкции это случилось.

Не прикладывайте файлы из каталога данных (`crm\`, `privacy\`, `codex-host\`) и из `.frontsmith\business\`: там хранятся рабочие данные и учётные записи.

## Профиль автосервиса (по желанию)

Отраслевой профиль выбирается только при первой установке профиля компании, поэтому для него нужен отдельный клон репозитория (шаги 2–3, затем `npm install`). Каталог данных и CRM у клонов на одном компьютере общие, профиль и офисная база — свои. В новом клоне:

```bash
npm run bootstrap -- --blueprint auto-service
npm run office:seed
```

Он добавляет разделы «Автомобили», «Заказы», «Выполненные работы» и учебные данные автосервиса.
