# Адаптеры

Адаптеры соединяют Frontsmith с внешними сервисами.

Целевые адаптеры v1.0:

- Vercel для публикации сайта
- Resend для доставки заявок
- Gmail для черновиков ответов и согласованных отправок
- Google Drive для материалов и документов
- Google Calendar для встреч

Адаптеры должны поддерживать пробный режим до реального выполнения. По умолчанию они готовят шаги подключения и действий, а выполняют их только после явного согласия владельца.
