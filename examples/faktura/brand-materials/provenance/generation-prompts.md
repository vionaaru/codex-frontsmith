# Задания генерации

Режим: встроенный imagegen, без CLI и OpenAI API key. Каждый файл создаётся отдельным запросом. Сведения ниже документируют происхождение синтетических материалов.

## logo/faktura-logo.png

Прозрачный фон: да

```text
Use case: logo-brand.
Asset type: original logo for fictional Russian-language furniture upholstery care service «Фактура».
Create one refined, legible horizontal logo lockup on a genuinely transparent background. A compact, original woven-textile symbol made of a few broad interlacing rounded bands, followed by the Cyrillic uppercase wordmark exactly «ФАКТУРА». Spell the seven letters Ф А К Т У Р А exactly; no Latin substitutions. Confident, calm, contemporary typography with generous clarity. The mark should suggest fabric structure and considered care without depicting cleaning tools or a sofa. One dark muted aubergine ink, flat solid shapes, vector-like crisp edges. The wordmark and mark form a balanced, compact usable logo with modest clear space, no huge empty margins. No tagline, no additional text, no mockup, no paper texture, no gradient, no glow, no 3D, no shadows, no checkerboard printed into the image. Output one high-resolution PNG logo with actual alpha transparency.
```
