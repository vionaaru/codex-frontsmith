# Универсальный профиль компании услуг

Профиль Frontsmith по умолчанию: `npm run bootstrap` на чистой установке создаёт цифровой офис из `business.example.json`.

- Клиентская база пустая: первый клиент создаётся в разделе «Клиенты» или командой `npm run office -- customer:add`, контакты сохраняются в CRM через CustomerProvider
- Каталог услуг пустой: услуги, цены и описания добавляет владелец
- Название, контакты, город и территория обслуживания — поля для заполнения, а не учебные значения
- Сайт строится из нейтрального шаблона `website/index.html` этого профиля
- Отраслевые разделы панели (автомобили, заказ-наряды, выполненные ремонты) выключены: `officeModules` пуст

Специализированные профили лежат рядом, например `blueprints/auto-service`. Явный выбор при первой установке:

```powershell
npm run bootstrap -- --blueprint auto-service
```

Существующая установка профиль не меняет: повторный `npm run bootstrap` оставляет `business.json` как есть.
