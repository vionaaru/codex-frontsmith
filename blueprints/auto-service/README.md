# Демонстрационный офис автосервиса

`business.example.json` — начальные данные вымышленного автосервиса «АвтоРитм»: восемь услуг, примерные цены на работу, часы, правила согласования и внешний адрес записи.

Названия услуг и длительность согласованы с интерфейсом Booking Flow. Цены придуманы для обучения; это не тарифы действующего автосервиса или сервиса записи. Адрес и рабочие контакты нужно заменить перед реальной эксплуатацией.

```powershell
npm run bootstrap
npm run first-run:status
npm run owner:brief
$env:CONTACT_DELIVERY_MODE = "dry-run"
npm run preview:website
```

Для явного профиля: `npm run bootstrap -- --profile blueprints/auto-service/business.example.json`.

Кнопки сайта открывают `https://example.com/booking` в новой вкладке. Это отдельная закрытая демоверсия, которая может запросить пароль. Пароли не хранятся в проекте, не включаются в ссылки и не передаются автоматически.

Записи во внешнем Booking Flow пока не импортируются в локальный офис. Переход на сайт не означает подключение API, календаря или email в Frontsmith.

## Состав профиля

- `services[].id` — технический код услуги
- `services[].priceFrom` — ориентир в рублях; 0 означает бесплатную консультацию, null — цену по согласованию
- `services[].durationMinutes` — продолжительность слота в примере
- `bookingUrl` — адрес внешней записи
- `pricingPolicy` — признаки демонстрационного прайса и требования согласования
- `demoMode` — признак учебных данных
- `hours`, `timeZone` — демонстрационный режим работы и московское время
- `integrations` — состояние подключений; внешний URL не является синхронизацией

Не использовать демонстрационный профиль для автоматической отправки цен клиентам.
